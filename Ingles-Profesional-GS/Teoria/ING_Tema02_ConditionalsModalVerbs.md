# Inglés Profesional GS - Tema 2: Conditionals and Modal Verbs

## 📌 Resumen Ejecutivo y Objetivos

Un condicional tiene dos partes: la **condición** (*if-clause*), que plantea la situación, y el **resultado** (*main clause*), que explica qué ocurre, qué ocurriría o qué habría ocurrido. El inglés marca ahí tres variables: cuánta realidad tiene la condición, cuándo se sitúa y qué certeza damos al resultado. De ahí salen los cuatro condicionales básicos —zero, first, second y third— y los **mixed**, que combinan dos momentos.

Los **verbos modales** (*can, could, must, have to, should, may, might*) no describen acciones, sino la actitud del hablante: capacidad, obligación, consejo, posibilidad o deducción. En soporte técnico son el motor de casi todas las frases: lo que el sistema puede hacer, lo que el usuario debe hacer y lo que probablemente ha fallado.

**Objetivos del tema:**

1. Identificar los cinco tipos de condicional y elegirlos por significado, no por traducción.
2. Producir las formas con exactitud: presente en la condición del first, *were* en el second, *had* + participio en el third.
3. Usar los conectores (*unless, as long as, provided that, even if, in case, when*) sin alterar el sentido.
4. Distinguir los valores de cada modal: habilidad, obligación, consejo, posibilidad y deducción.
5. Aplicar ambos sistemas a la comunicación profesional: reclamaciones, errores e hipótesis técnicas.

## 📖 Desarrollo Teórico Detallado

### Cómo se lee un condicional

La condición plantea la situación; el resultado, la consecuencia. Si empieza por *if*, hay coma: *If the server crashes, we will restart it.* Si el resultado va primero, no: *We will restart it if the server crashes.*

| Parte | Función | Ejemplo |
|---|---|---|
| **If-clause** | condición | *If the server crashes,* |
| **Main clause** | resultado | *we will restart it.* |

Regla de oro: los tiempos se eligen **en pareja**.

### Zero conditional: hechos y procesos automáticos

**If + Present Simple, Present Simple.** Siempre que ocurre la condición se produce el resultado: leyes físicas y funcionamiento de sistemas.

- *If the CPU overheats, the system shuts down.* — Si la CPU se sobrecalienta, el sistema se apaga.
- *If you enter the wrong password three times, the account locks.* — Si fallas la contraseña tres veces, la cuenta se bloquea.

*When* puede sustituir a *if*: *When the battery runs out, the device switches off.*

### First conditional: posibilidades reales

**If + Present Simple, will + infinitivo.** Situaciones reales o posibles en el futuro y sus consecuencias probables.

- *If we find the bug, we will fix it.* — Si encontramos el error, lo corregiremos.
- *If the client calls, I will send him the report.* — Si el cliente llama, le enviaré el informe.

También caben **may, might, can, should** o un **imperativo**: *If the screen freezes, restart the computer.*

### Second conditional: situaciones imaginarias

**If + Past Simple, would + infinitivo.** Hipótesis irreales en presente o futuro; también sirve para aconsejar.

- *If I had more RAM, I would run the program.* — Si tuviera más RAM, ejecutaría el programa.
- *If I were you, I would reinstall the application.* — Yo que tú, reinstalaría la aplicación.

El **Past Simple aquí no indica pasado**, sino irrealidad; en registros formales se prefiere **were** con todas las personas.

### Third conditional: un pasado diferente

**If + Past Perfect, would have + participio.** Imagina un pasado que no ocurrió: errores y consecuencias evitables.

- *If we had backed up the files, we wouldn't have lost the data.* — Si hubiéramos hecho copia, no habríamos perdido los datos.
- *If I had known about the error yesterday, I would have fixed it.* — Si hubiera sabido del error ayer, lo habría arreglado.

Realidad implícita: no hicimos copia. También caben **could have / might have** + participio.

### Mixed conditionals: dos momentos distintos

**A. Condición pasada → resultado presente: If + Past Perfect, would + infinitivo.**

- *If we had updated the software yesterday, it would work properly now.* — Si lo hubiéramos actualizado ayer, ahora funcionaría bien.

**B. Condición presente → resultado pasado: If + Past Simple, would have + participio.**

- *If I were more experienced, I would have solved the problem yesterday.* — Si tuviera más experiencia, lo habría resuelto ayer.

La pista está en los marcadores: *now, today* → presente; *yesterday* → pasado.

### Tabla resumen de condicionales

| Tipo | If-clause | Main clause | Uso | Ejemplo |
|---|---|---|---|---|
| **Zero** | Present Simple | Present Simple | hechos automáticos | *If the CPU overheats, it shuts down.* |
| **First** | Present Simple | will + inf. (o may/might/can) | posibilidad real futura | *If we find the bug, we will fix it.* |
| **Second** | Past Simple (*were*) | would + inf. (o could/might) | hipótesis; consejo | *If I had more RAM, I would run it.* |
| **Third** | Past Perfect | would have + participio | pasado imaginario | *If we had backed up, we wouldn't have lost the data.* |
| **Mixed A** | Past Perfect | would + inf. | causa pasada, efecto presente | *If we had updated it, it would work now.* |
| **Mixed B** | Past Simple | would have + participio | rasgo presente, efecto pasado | *If I were experienced, I would have solved it.* |

Mnemotecnia: **un paso atrás en la condición y otro en el resultado**.

### Conectores condicionales

| Conector | Significado | Ejemplo técnico |
|---|---|---|
| **Unless** | a menos que / si no (= *if ... not*) | *The app won't work unless you update it.* |
| **As long as** | siempre que | *You can access it as long as you have permission.* |
| **Provided that** | a condición de que (formal) | *We will release it provided that tests pass.* |
| **Even if** | incluso si | *We will continue even if the server goes down.* |
| **In case** | por si acaso | *Save a backup in case it crashes.* |
| **When** | cuando (+ presente) | *When the installation finishes, restart the device.* |

Dos contrastes de examen:

- **in case / if.** *Take a screenshot in case the error disappears* (por precaución) / *if the error appears* (solo si aparece).
- **if / even if.** *If the server fails, we will use the backup* (si falla) / *Even if it fails, we will complete the presentation* (aunque falle).

**Unless** ya contiene la negación: *Unless you don't restart the router...* ✗ → *Unless you restart the router, it won't work* ✓.

### Errores frecuentes

- **Nunca *will* tras *if*:** ✗ *If you will restart it...* → ✓ *If you restart it, it will work.*
- **Nunca *would* / *would have* en la condición:** ✗ *If I would have more RAM...* → ✓ *If I had more RAM, I would run it.*
- **Pasado hipotético con *had known*:** ✗ *If I knew yesterday...* → ✓ *If I had known, I would have fixed it.*

### Modal verbs: forma y reglas generales

Los modales son auxiliares defectivos:

1. **Sin -s en tercera persona**: *he can*, no *he cans*.
2. **Seguidos de infinitivo sin *to***: *she must restart*. Excepciones: *have to*, *ought to*.
3. **Sin do/does/did**: *Can you help me?*, no *Do you can help me?*; negativo *cannot / can't*.
4. **No se combinan entre sí**: *He might can fix it* ✗ → *He might be able to fix it* ✓.

Sin tiempo propio, usan perífrasis: *can* → *be able to*; *must* → *have to*.

### Ability: can, could, be able to

- **can** — capacidad presente: *I can reset the password remotely.* — Puedo restablecer la contraseña en remoto.
- **could** — capacidad pasada general o petición cortés: *Could you send me the log file?* — ¿Podría enviarme el archivo de registro?
- **be able to** — todo tiempo y logro concreto: *We weren't able to reproduce it.* — No pudimos reproducirlo.

Matiz: *could* es capacidad general (sabía hacerlo); *was able to* o *managed to*, logro puntual (lo consiguió).

### Obligation and necessity: must, have to, need to

- **must** — obligación fuerte, interna o impuesta por el hablante; normas: *You must change the default password.* — Debes cambiar la contraseña por defecto.
- **have to** — obligación externa: *We have to follow the SLA.* — Tenemos que cumplir el acuerdo de nivel de servicio. En pasado y futuro solo existe *have to*: *I had to reinstall the system.*
- **need to** — necesidad práctica: *You need to restart the service.*

**Don't have to** = no es necesario (*You don't have to come on Saturday*); **mustn't** = prohibición (*You mustn't share the password*).

### Advice: should, ought to, had better

- **should** — recomendación neutra, la más útil en soporte: *You should clear the browser cache.* — Debería vaciar la caché. Negativo: *You shouldn't open unknown attachments.*
- **ought to** — equivalente formal: *You ought to update the drivers.*
- **had better** — consejo con advertencia: *You'd better save your work before restarting.* — Más te vale guardar el trabajo. Negativo: *had better not*.

### Possibility: may, might, could

- **may** — posibilidad real, formal: *The server may be offline.* — Puede que el servidor esté caído.
- **might** — posibilidad remota: *It might be a network issue.* — Podría ser un problema de red.
- **could** — posibilidad teórica: *A wrong configuration could cause this error.* — Una configuración incorrecta podría causar este error.

En el first conditional sustituyen a *will*: *If the patch fails, we might need a rollback.*

### Deduction: must, may/might/could, can't

Aquí expresan **lo que deducimos** de la evidencia.

| Grado | Modal | Ejemplo | Lectura |
|---|---|---|---|
| Certeza afirmativa | **must** | *The database must be down: nobody can log in.* | Es seguro. |
| Posibilidad | **may / might / could** | *The router might be overheating.* | Es posible. |
| Certeza negativa | **can't** | *It can't be a hardware failure: the logs show a timeout.* | Es imposible. |

Error clásico: en negativo se usa **can't**, no *mustn't*. *He mustn't be at work* ✗ → *He can't be at work* ✓.

### Modals in the technical support context

En soporte aparecen en fórmulas fijas:

| Función | Fórmula | Traducción |
|---|---|---|
| Pedir paciencia | *Could you bear with me, please?* | ¿Podría esperar un momento? |
| Disculparse | *I do apologize for the delay.* | Le pido disculpas por la demora. |
| Reconocer el problema | *I'm afraid we've been having problems.* | Me temo que hemos tenido problemas. |
| Comprometerse | *I'll get onto it right away.* | Me pongo con ello ahora mismo. |
| Dar instrucciones | *You need to restart the router. You shouldn't unplug it while it updates.* | Tiene que reiniciarlo. No debería desenchufarlo mientras se actualiza. |
| Explicar hipótesis | *It might be a DNS problem. It can't be the firewall: the port is open.* | Podría ser DNS. No puede ser el cortafuegos. |

## 💡 Ejemplos Prácticos y Aplicaciones

### Diálogo de helpdesk

**Agent:** Good morning, Technical Support. How can I help you?
**Customer:** My application keeps crashing when I export a report.
**Agent:** I'm very sorry. **Could** you tell me which version you are using?
**Customer:** Version 3.2.
**Agent:** **It might be** a memory problem. **If** the report is very large, the app **will close** without warning. **You should** increase the memory limit.
**Customer:** And if that doesn't work?
**Agent:** **If** it continues, **we will escalate** it. **Could you bear with me** a moment, please? **I'm afraid we've been having** issues with the export module since the last release. **If we had tested** it properly, **we wouldn't have released** a faulty version.

Traducción: *If we had tested it properly, we wouldn't have released a faulty version* (si lo hubiéramos probado bien, no habríamos publicado una versión defectuosa).

### Aplicación profesional: instrucciones al usuario

*First, you must back up your data. Then you should restart the device in safe mode. You mustn't interrupt the process.*

## ⚠️ Conceptos Clave para Examen y Preguntas de Autoevaluación

### Conceptos clave

1. **Estructura bimembre**: *if-clause* (condición) + *main clause* (resultado); coma si *if* va primero.
2. **Zero**: presente → presente; hechos automáticos.
3. **First**: presente → *will* + infinitivo; posibilidad real. Nunca *will* tras *if*.
4. **Second**: Past Simple (*were*) → *would* + infinitivo; irrealidad y consejo.
5. **Third**: Past Perfect → *would have* + participio; pasado imaginario.
6. **Mixed**: pasado→presente (*had done → would be*) y presente→pasado (*were → would have done*).
7. ***Unless*** = *if ... not*, sin doble negación; ***in case*** = precaución; ***even if*** = el resultado no cambia.
8. **Modales**: sin -s, sin *to*, sin *do/does*, nunca dos juntos.
9. **Ability**: *can*, *could* (pasado general), *be able to* (cualquier tiempo; logro puntual).
10. **Obligation**: *must* (interna), *have to* (externa); *don't have to* ≠ *mustn't*.
11. **Deduction**: *must* (seguro), *may/might/could* (posible), *can't* (imposible).

### Preguntas de autoevaluación

**1. ¿Por qué es incorrecto *If you will call me, I will help you*?**
En la *if-clause* del first conditional no se usa *will*: la condición va en presente.

**2. *If I ______ (be) you, I would reinstall the application.* ¿Qué forma y qué valor tiene?**
*were*. Second conditional; se prefiere *were* con todas las personas. Expresa consejo.

**3. Diferencia entre *If we had backed up the files, we wouldn't have lost the data* y *If we backed up the files every night, we wouldn't lose data*.**
La primera es third: un pasado que no ocurrió y su consecuencia. La segunda es second: una rutina hipotética presente.

**4. ¿Por qué *If I would have more RAM* es incorrecto?**
Porque en la condición del second no se usa *would*, sino Past Simple: *If I had more RAM, I would run it*.

**5. Reescribe con *unless*: *If you don't restart the router, it won't work*.**
*Unless you restart the router, it won't work.* *Unless* ya significa "si no": el verbo pasa a afirmativo.

**6. Diferencia entre *Take a screenshot in case the error appears* y *Take a screenshot if the error appears*.**
*In case* = hazlo por precaución; *if* = solo cuando aparezca.

**7. *The database ______ be down: nobody can log in.* ¿must, might o can't?**
*must*: deducción con evidencia fuerte. *Might* sería simple posibilidad; *can't*, imposibilidad.

**8. Diferencia entre *You don't have to restart the server* y *You mustn't restart the server*.**
*Don't have to* = no es necesario; *mustn't* = está prohibido.

**9. Corrige y explica: *He mustn't be at the office, because his computer is off*.**
*He can't be at the office...* Para una deducción negativa se usa *can't*; *mustn't* expresa prohibición.

**10. Traduce combinando ambos sistemas: "Si hubiéramos probado el módulo, la aplicación funcionaría ahora".**
*If we had tested the module, the application would work now.* Mixed A: condición pasada y resultado presente, señalado por *now*.
